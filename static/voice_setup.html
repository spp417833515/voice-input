手机或其他电脑扫码打开录音页，说的话会输入到这台电脑当前的光标处。

使用步骤

  1. 确保手机 / 其他设备与这台电脑连同一个 WiFi / 局域网。
  2. 用手机扫描下方二维码（或手动输入网址）。
  3. 首次打开手机会提示“证书不安全 / 连接不是私密”——这是本机自签证书， 点“高级 → 继续前往”即可（局域网自用，安全）。
  4. 在手机上按住麦克风说话，松开即自动转写并输入到电脑。
  5. 输入前请把电脑焦点放在目标输入框（聊天框 / 文档等）。
