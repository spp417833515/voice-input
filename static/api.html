POST/api/v1/stt 局域网

纯语音转文字：上传音频 → 返回文本。不注入、不入队、不写历史。

字段类型说明
audiofile音频文件（wav/webm/opus/mp4/m4a/ogg… 任意）
tokenstring访问令牌
languagestring可选，默认 zh；可填 en/ja/ko/… 或 auto
返回：{ "ok": true, "text": "识别文字", "language": "zh" }

POST/api/web_input/resend 局域网

远程打字：把一段文本注入到本机当前焦点窗口（复用注入队列，带状态回传）。

字段类型说明
tokenstring访问令牌
textstring要打进本机的文本
返回：{ "ok": true, "job_id": "…" }，可用 /api/web_input/status 查进度。

POST/api/web_input/submit 局域网

录音即打字：上传音频 → 转写 → 注入本机 + 返回文本与 job_id（手机录音页用的就是它）。

字段同 /api/v1/stt。返回：{ "ok": true, "text": "…", "job_id": "…" }

其他只读接口 局域网

接口说明
GET /api/web_input/status?token=&job_id=查询某次注入的实时状态
GET /api/web_input/history?token=&limit=最近输入历史
🔒 安全：以上接口均需 token；装软件 / 删模型 / 改配置等危险操作仅本机可访问，局域网无法调用，也无法伪造注入结果。服务使用自签证书，脚本调用请忽略证书校验（curl -k / Python verify=False）。
