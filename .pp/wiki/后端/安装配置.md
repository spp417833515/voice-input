# 安装配置

## 一句话定位

`static/setup.html` 单页 UI 配套的 8 个 setup API，覆盖环境自检、ollama 安装/启动/拉模型/删模型、whisper 预加载/删除、运行时切换 8 项配置并持久化到 `.config.json`。

## 关联代码路径

- `app.py:199-211` 页面路由 `/`、`/setup`、`/history`
- `app.py:356-425` `setup_check` — 扫描 whisper 缓存 + ollama 健康 + 系统工具，返回大 JSON
- `app.py:428-452` `pull_model` — SSE 流式包装 ollama `/api/pull`
- `app.py:455-472` `delete_model` — DELETE 到 ollama `/api/delete`
- `app.py:475-498` `install_ollama` — 调官方 `curl install.sh | sh`
- `app.py:501-531` `start_ollama` — systemctl → Popen 兜底，10 秒轮询就绪
- `app.py:534-585` `set_config` — 9 个 Form 字段，仅持久化变化项
- `app.py:588-602` `preload_whisper` — 异步加载，触发 HuggingFace 下载
- `app.py:605-628` `delete_whisper` — `shutil.rmtree` 匹配目录
- `app.py:45-90` `_load_config / _save_config` — `.config.json` 合并写
- `static/setup.html` — 配套前端

## 功能节点说明

- check 输出结构：`ollama / ollama_models / whisper / system_tools / config`，前端按字段渲染开关与按钮。
- pull SSE 协议：`data: {json}\n\n` 行；终止帧 `data: {"status":"done"}`。`X-Accel-Buffering: no` 关 Nginx 缓冲。
- set_config 持久化语义：仅有变化的字段进入 `changed` 字典并返回；空字符串视为「清空」（baidu 字段允许）。
- whisper 重置：切换模型时 `_whisper_model = None` 触发下一次 `get_whisper_model()` 重新加载。

## 关联复用

- 无 L5 复用单元（每个 endpoint 都是独立调用）。
