# 语音录入

## 一句话定位

按住快捷键 → `sounddevice` 单声道 float32 录音 → 队列异步送 `/api/transcribe` → 用 `_type_text` 把结果注入到当前焦点窗口 → 保护并恢复用户原剪贴板。

## 关联代码路径

- `daemon.py:1329-1490` `class VoiceRecorder`

  - `start()` 启 `sd.InputStream` + 400Hz 低音 beep（daemon.py:1339-1376）

## 功能节点说明

- 录音帧 → numpy ndarray 列表 → concatenate；极短录音（<0.15s）视作误触不送 API。
- 队列：`queue.Queue[np.ndarray]` + 单后台 worker，保证顺序处理；排队时状态栏显示「已排队，前方 N 条」。
- 末尾标点：根据 `WHISPER_LANGUAGE` 自动加 `。` (zh/ja/ko) 或 `.`（其他），不重复添加（已有 `。！？.!?…；;:：,，、` 之一则跳过）。
- 剪贴板保护：粘贴前保存 `old_clipboard`，粘贴后 sleep 0.3s 再读；若当前剪贴板仍是本次结果则恢复 old，避免覆盖用户在粘贴瞬间复制的新内容。
- `_type_text` 四级 fallback：Tier1 IBus 直接 commit（最优，无剪贴板副作用）→ Tier2 Wayland=uinput / X11=xdotool → Tier3 Wayland=wtype / X11=uinput → Tier4 pynput XTest（仅 X11）。终端检测 `_is_terminal_focused()` 决定是否加 Shift。
- 修饰键泄漏防护：uinput / pynput 路径都用 `try/finally` 释放，并调用 `_force_clear_uinput_mods` / `_force_clear_pynput_mods` 兜底。
