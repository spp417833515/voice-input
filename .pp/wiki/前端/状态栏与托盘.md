# 状态栏与托盘

## 一句话定位

`StatusBar` 是常驻左下角的悬浮 GTK Window（透明、置顶、可拖拽），实时反馈录音/转写/截图状态；`_create_tray_icon` 用 AppIndicator3 提供系统托盘入口（设置/关于/显示状态栏 toggle）。

## 关联代码路径

- `daemon.py:838-975` `class StatusBar(Gtk.Window)` — 状态栏窗口
- `daemon.py:916-924` `_position_bottom_left` — 主屏底部左侧定位
- `daemon.py:926-955` `update_status(text, style)` — 图标 + CSS class 同步切换
- `daemon.py:957-975` `_on_press / _on_release / _on_motion` — 手动拖拽（begin_move_drag 在 XWayland 静默失败，所以走 `move(x,y)`）
- `daemon.py:983-1008` `_show_about / _open_settings` — 菜单回调
- `daemon.py:1011-1061` `_create_tray_icon` — AppIndicator3 创建与菜单组装
- `daemon.py:2342-2345` `main()` 中初始化两者

## 功能节点说明

- 状态栏的 5 种 style：`recording 🔴 / busy ⏳ / error ⚠ / success ✓ / normal 🎤`，每种对应一个 CSS class（`status-recording / status-busy / status-error / status-success`）。
- 文字截短：超过 12 字符尝试匹配关键词（"录音 / 转写 / 已输入 / 截图 / 失败 / 太短 / 排队 / 识别 / 就绪 / 重复"）取一个短词，匹配不到就 `text[:10] + "…"`。
- 透明窗口：`screen.get_rgba_visual() + set_app_paintable(True)`，无装饰、跳过任务栏、type_hint=UTILITY。
- 拖拽：维护 `_dragging / _drag_offset / _win_pos`，在 motion 中累积偏移并 `self.move(int(ox+dx), int(oy+dy))`。
- 托盘策略：**不提供退出菜单**（注释 daemon.py:1055 明确：daemon 是基础设施，真停只能用 `systemctl --user stop ollama-voice-daemon`）。
- 显示/隐藏状态栏 toggle：通过 `_status_bar.show_all() / hide()` 切换，不销毁。

## 关联复用

- 无 L5 复用单元（StatusBar 是单例，托盘函数也是单例）。
