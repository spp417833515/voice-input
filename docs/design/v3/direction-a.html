设置/管理页 · 数据与动作

显示的数据

  • 模型状态：ASR 模型名、是否下载、大小、运行设备；Ollama 安装/运行/版本；qwen3.5:4b 是否下载；下载进度（已下/总量/百分比）与失败原因
  • 配置：润色开关、关键词、截图目标语言（含仅识别）、三个快捷键、是否需重启的提示
  • 手机入口：每个局域网 IP 的网址与二维码、令牌
  • 最近记录：时间、来源（本机/手机/重发）、润色状态、最终文本、原文
  • 系统检测：平台能力列表（名称/可用/安装命令）、版本号

动作 → 接口

  • 打开、刷新状态 → status get（含 config get）
  • 下载语音模型 → asr model download（流式进度）
  • 安装 / 启动 Ollama → ollama install / ollama start
  • 下载 qwen3.5:4b → model pull（流式进度）
  • 润色开关、保存关键词、目标语言、保存快捷键 → config set
  • 手机入口、令牌、服务地址 → lan entry get；复制只走本地剪贴板
  • 最近记录、加载更多 → history list(limit, offset)

状态

  • 加载中、全部就绪、模型下载中、Ollama 未运行、服务不可达（上方状态切换，左侧菜单切页）；无记录、无局域网 IP 的空状态见页内灰字

为什么最简

  • 左侧 8 个菜单、右侧每页只有一段内容，没有二级结构；模型固定，所以模型页只有两行、每行最多一个按钮；历史、手机入口和接口文档并入同一窗口，不再有 4 个独立页面

状态栏 + 实时字幕 · 数据与动作

显示的数据（本地服务推送的状态事件 status events）

  • 状态：空闲 / 录音中 / 润色中 / 已输入 / 错误（含错误码与原因）
  • 录音中：已录时长；recognize stream 的部分结果 = 已稳定文本 + 未稳定尾部（尾部由后端划定，前端只负责蓝色虚下划线着色）
  • 松开后：定稿原文；润色后的文本；输入方式结果
  • 错误时：原因 + 可用的补发键（从配置读，不写死）

动作 → 接口

  • 按住/松开语音键（平台层热键）→ recognize stream 开始/结束 → 定稿 → polish（开关开时）→ type
  • 重复键 → repeat last：润色失败时补发原文，焦点切走时重新输入
  • 胶囊可拖动（与现状一致，不持久化）；托盘"显示悬浮状态栏"开关保留

规则

  • 字幕最宽 520px、最多两行，超出时只露最新两行
  • 润色关闭时松开直接"已输入"，不出现"润色中"
  • 连说多句时显示"已排队，前方 N 条"（busy 色）
  • 截图流程复用同一胶囊：截图中 / 识别翻译中 / 翻译完成 / 失败原因

截图翻译浮窗 · 数据与动作

显示的数据

  • 选区矩形（平台层选区给出，浮窗贴着它）
  • ocr-translate 返回：整段译文（本方向只需整段，不需要逐行坐标）；仅识别模式下为识别文字
  • 失败：错误原因原文（OCR 失败 / 没有识别到文字 / 本地模型未运行 / 翻译失败）

动作 → 接口

  • 截图键 → 平台层选区 → ocr-translate(image, target_lang)
  • 复制 → 本地剪贴板（复制后按钮变"已复制"）
  • Esc / 点击浮窗外 / 结果出现 10 秒后 → 关闭；加载最长 30 秒强制关闭（保持现有安全上限）

规则

  • 浮窗宽度不小于选区（最小 200×60），译文更长时向下长高
  • 翻译失败只显示错误，不把识别原文当译文显示（去掉现在的"已显示原文"回退）

手机录音页 · 数据与动作

显示的数据

  • 令牌校验结果（lan info）、语言
  • 处理阶段：上传 → 识别中 → 润色中 → 等待电脑 → 已输入 / 失败原因
  • 最终文本、润色状态；润色失败时的识别原文
  • 最近 5 条输入（文本、来源、时间）

动作 → 接口

  • 按住录音、松开上传 → phone submit（音频 → recognize + polish → 输入任务），返回任务号
  • 阶段与结果 → job status 轮询（或事件流）
  • 点历史、"发送原文" → resend(text)
  • 刷新 → history list(limit=5)
  • 非 https 时 → 系统录音上传，同 phone submit
  • 改快捷键 → 浏览器本地存储（无接口，同现状）

保留的现有规则

  • 录音短于 0.4 秒提示"录音太短"；麦克风无权限显示原因；20 秒未收到电脑确认提示"电脑端服务是否在运行"
