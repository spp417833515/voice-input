## 本周安排

状态胶囊 + 字幕条 · 数据与动作

显示的数据（status events 事件流）

  • 胶囊：状态、录音时长、输入电平（录音时的音量跳动，需要事件流带电平值）
  • 字幕：recognize stream 部分结果 = 已稳定文本 + 未稳定尾部（后端划定）；定稿原文；润色后文本
  • 改动高亮：润色结果里的修改片段（后端给出）；若后端不给，只显示润色后文本
  • 错误：原因原文 + 补发键（读配置）

动作 → 接口

  • 按住/松开语音键（平台层）→ recognize stream → polish → type
  • 重复键 → repeat last（润色失败发原文 / 焦点切走重输）
  • 胶囊可拖动；字幕条固定在当前屏幕底部居中，只在录音到输入完成期间出现，完成 1.5 秒后淡出

规则

  • 字幕两行 20px 大字，超出只露最新两行；未稳定尾部用浅紫色 + 光标
  • 润色关闭时松开直接显示"已输入"，无高亮
  • 截图流程只用胶囊（截图中 / 识别翻译中 / 完成 / 失败），不出字幕条

逐行原位翻译 · 数据与动作

显示的数据

  • 选区矩形（平台层）
  • ocr-translate 返回每一行：原文、行框坐标（相对选区）、该行译文；可选该行背景色（用来铺补丁，避免前端自己取色）
  • 仅识别模式：每行原文与坐标（虚线框标出）
  • 失败：原因原文

动作 → 接口

  • 截图键 → 平台层选区 → ocr-translate(image, target_lang)
  • 译文/原文切换：只隐藏补丁，无接口
  • 复制译文 / 复制原文 / 复制文字 → 本地剪贴板
  • 打开设置（失败时）→ 打开设置窗口的模型页
  • Esc / 点击外部 / 10 秒无操作 → 关闭；加载 30 秒强制关闭

风险（需后端确认）

  • 逐行翻译会把一句话拆在两行分别翻，语序可能别扭；建议后端按段翻译后再分回各行，由后端决定每行显示什么，前端只按坐标贴
  • 译文比原文长时缩小字号到行高内，最小 12px，仍放不下则截断并在复制里给全文
